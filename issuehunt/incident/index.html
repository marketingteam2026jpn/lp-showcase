選ばれる理由

インシデント後に頼れる、4つの理由

01

SPEED即日契約、翌日診断、2日後に報告。※2

インシデント後は一日でも早く「もう大丈夫」と言える状態が必要です。AIが検査箇所を洗い出すので、診断対象の一覧づくりを待たずにすぐ始められます。

D+0相談・契約D+1診断実施D+2報告・対策提示
02

FIND今回とは別の「残る穴」まで洗い出す。

AIがソースコードを読み取り、検査する場所を広く洗い出します。権限の抜けや業務ロジックの穴など、ツールでは見つけにくい部分は診断員が手で確かめます。

03

FIX見つけて終わりにせず、直し方まで。

弱点ごとに再現手順・具体的な修正方法・対策手順をお渡しします。開発担当や保守会社にそのまま修正を依頼できます。修正後は無料の再診断で、直ったことまで確認します。

04

EXPLAIN「何を調べたか」を示せるレポート。

一般的なレポートは見つかった脆弱性の一覧だけです。IssueHunt One は検査した箇所と試した攻撃の内容まで開示します。経営層・取引先・お客様への再発防止策の説明に、そのまま使えます。

レポート見本

直し方と、調べた範囲。
両方を一冊に。

重大度：高IH-2026-0721

会員検索APIからSQLインジェクションが可能

対象
GET /api/members/search?q=
影響
検索文字列に細工をすると、会員テーブルの氏名・メールアドレス・住所を一括で取得できます。今回のインシデントとは別の経路です。
再現手順
  1. ログインせずに会員検索APIを呼び出す
  2. 検索文字列に細工した値を入れる
  3. 本来見えない会員情報が返ってくる
# 修正方法：入力値を直接SQLに埋め込まず、プレースホルダを使う
- db.query("SELECT * FROM members WHERE name LIKE '%" + q + "%'")
+ db.query("SELECT * FROM members WHERE name LIKE ?", ["%" + q + "%"])

よくあるご質問

ご依頼前によくいただく質問

被害の調査や復旧もお願いできますか。

初動対応（被害範囲の調査・封じ込め・復旧）は対象外です。IssueHunt One は、初動のあとに残る弱点を見つけて再発を防ぐための診断と、対策のご提示を行います。

本当に2日で報告してもらえますか。

AI自動診断なら、最短で即日契約・翌日診断・2日後報告が可能です。AIエージェントが自律的に診断します。診断員による手動診断は翌日の実施ができず、診断完了まで一定の期間がかかります。診断する範囲や規模によっても日数は変わるため、ご相談時に具体的な日程をお伝えします。

見つかった問題は、どこまで対応してもらえますか。

問題ごとに、起きる手順と具体的な修正方法・対策手順をお伝えします。開発担当や保守会社がそのまま修正に入れる内容です。修正後は無料の再診断で、問題が解消されたかを確認します。

社内にセキュリティの担当者がいません。

問題ありません。AIが検査箇所を洗い出すため、診断対象の一覧をご用意いただく必要はありません。レポートは専門知識がなくても読める形でお渡しします。

本番環境に影響は出ませんか。

検証環境での実施をおすすめしています。本番環境で行う場合は、実施日時や検査の強さを事前に取り決めたうえで進めます。

費用はどのくらいですか。

検査するエンドポイント数に応じたプランでご案内します。AIで作業の一部を自動化しているため、相場の約半額でご提供しています。お見積もりは無料です。
